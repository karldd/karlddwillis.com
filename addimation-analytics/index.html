Addimation Analytics

Addimation Analytics is a data analytics service to improve production efficiency in additive manufacturing (AM). By capturing key AM production metrics in real-time we enable a new level of transparency and understanding of events happening on the production floor. Despite the heavy investment in additive manufacturing technologies, answering basic questions about production metrics e.g. how much material was used this month?, is still very difficult.

Addimation Analytics solves this problem with a software data aggregator that listens to and decodes network and log activity into meaningful production information. That information is then stored in the cloud and made accessible through a real-time analytics web interface. Addimation Analytics supports Stratasys FDM and Polyjet 3D printers. Addimation Analytics was acquired by FATHOM in November 2015.
